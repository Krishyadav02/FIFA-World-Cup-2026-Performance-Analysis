# ⚽ FIFA World Cup 2026 Performance Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing FIFA World Cup 2026 player performance and match statistics using Microsoft Excel and Microsoft Power BI.

The project started with collecting the dataset from Kaggle. After collecting the data, the dataset was cleaned and prepared in Microsoft Excel by removing duplicates, handling missing values, correcting data types, formatting columns, and ensuring data consistency.

Once the dataset was cleaned, it was imported into Microsoft Power BI to build an interactive dashboard. The dashboard allows users to analyze player performance, match results, host cities, and tournament insights using dynamic filters and visualizations.

---

## 🎯 Project Objectives

- Analyze FIFA World Cup 2026 player performance.
- Clean and prepare raw data for analysis.
- Create an interactive Power BI dashboard.
- Provide meaningful insights through visualizations.
- Enable dynamic filtering for better data exploration.
